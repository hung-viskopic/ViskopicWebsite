# Viskopic

Viskopic's public website and document-intake research workspace.

- The repository root contains the static marketing website.
- `platform/` contains the React workspace, NestJS API, PostgreSQL migrations, and Python extraction worker.
- `render.yaml` defines the Render services.
- `DEPLOYMENT.md` contains the Supabase, Render, and GoDaddy setup procedure.

Local application instructions are in `platform/README.md`.
